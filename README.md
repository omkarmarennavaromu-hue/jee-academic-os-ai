# OMKAR — JEE ACADEMIC OS
111 days · 46 chapters · one execution system. JEE Main 2027 (January attempt).

## Run it on Windows
1. Install Node.js (LTS) from nodejs.org
2. In this folder: `npm install` then `npm run dev` → open http://localhost:5173 in Chrome/Edge
3. Production build: `npm run build` then `npm run preview` (or host the `dist/` folder anywhere static)

## Key facts
- Day 1 = 6 Oct 2026 · Day 111 = 24 Jan 2027 (auto-calculated from Settings → start date)
- Phases: 1–36 Build the Core (Tier 1) · 37–70 Sweep the Rest (Tier 2) · 71–94 Full Revision (2nd pass, all 46) · 95–111 Final Sprint + Taper
- Mock slots: Days 42, 56, 70 (part syllabus) · 77, 84, 91 · 96, 99, 102, 105, 108 · Day 36 = Tier 1 checkpoint
- Completing a chapter auto-schedules +2 / +10 / +30 day recall + its Phase 3 slot
- Missed days never shift the calendar — recover tasks via Do Today / Light Slot / Skip
- All data in localStorage. Export a JSON backup from Settings regularly.
- Installable as a PWA (Chrome/Edge → Install app). Works offline after first load (production build).
